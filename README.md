# shadcn-libra

Revived shadcn/ui-inspired component library for EzMenus projection blocks.

## Scripts

- `npm install`
- `npm run lint`
- `npm run type-check`
- `npm run build`
- `npm run storybook`
- `npm run build-storybook`

## Styles

Import `@ezmenus/shadcn-libra/styles.css` for the full Tailwind-powered base styles.
Import `@ezmenus/shadcn-libra/theme.css` when you only need the CSS variable theme tokens.
